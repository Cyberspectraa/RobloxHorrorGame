# Asset manifest / provenance register
Status: no final in-game art or audio registered at project initialization.

Every entry must record: ID/filename, purpose, creator, creation method, source URL or original project path, licence/permission, date, Roblox uploaded asset ID, game location, optimization/export status, and approval. Do not claim a Creative Commons license without verifying its terms. Asset authorship and permission must be checked before publishing.

## Required packs
1. Brand: hand-authored stencil logotype, station seal, title card, game icon, thumbnails.
2. World: modular damp concrete, salt-damaged copper ducts, labelled switchgear, tape machines, industrial glass and door parts.
3. Creature: custom mesh, authored rig, walk/investigate/idle/search/capture animations and contact/ceramic details.
4. Props: hand-crank light, decoy, schematic, spools, recorder, breaker switches, intake valves.
5. Audio: drone/metallic/pulse/air stems, unique regional ambience, relay knocks, machine SFX and original authored dialogue.
6. Interface: subtle paper grain (original photo/texture), machine iconography, responsive menu layers, caption glyphs.

All reference photographs used for moodboards are REFERENCE ONLY and MUST NOT be uploaded as textures unless licensed. No marketplace asset IDs or fake sound IDs are committed as if working.
